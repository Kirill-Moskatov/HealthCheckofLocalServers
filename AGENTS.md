## О проекте

**Pulse** — личный дашборд healthcheck домашних сервисов (Home Assistant, Immich).
Живёт на внешнем сервере (1 vCPU / 1 ГБ, рядом Amnezia VPN), раз в 20 минут проверяет
сервисы по внешним KeenDNS-адресам, ведёт историю за 3 месяца (аптайм/простой за 10 недель),
шлёт уведомления в MAX (пока мок). Авторизация — Casdoor (Yandex / VK / пароль).

**Стек**: Python 3.12 · FastAPI · SQLite · SQLAlchemy · APScheduler · httpx · pydantic-settings · фронт без сборки (M3-стили) · Casdoor · Docker Compose.

## Ключевые решения (кратко)

- HA проверяем по `/manifest.json` (его `/api/` отдаёт 401 без токена — это не сбой); Immich — `/api/server/ping`; у сервиса настраиваемый `expected_status`.
- Порог сбоя = 1 неудачная проверка (интервал 20 минут).
- MAX-бот — мок (`Notifier` → `MAXMockNotifier`, лог в БД); реальный бот — после появления токена.
- Авторизация (этап 4) строго до публичного деплоя (этап 5).
- IAM — Casdoor: Yandex + VK + пароль из коробки, лёгкий; Keycloak/Authentik не проходят по памяти.
